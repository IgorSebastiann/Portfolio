# Portfólio — Igor Sebastian Mathias

Portfólio pessoal moderno para apresentar minha atuação em automação RPA, Python, IA aplicada e desenvolvimento de software.

## Conceito

A interface usa uma linguagem visual de sistema técnico: tipografia expressiva, alto contraste, grid discreto e uma malha de dados interativa. O cenário reage ao scroll e ao cursor, passando de uma composição concentrada no hero para diferentes movimentos ao longo da página. Em dispositivos móveis, a densidade visual é reduzida; com `prefers-reduced-motion`, o cenário permanece estático.

## Executar localmente

Requer Node.js 22 ou superior.

```bash
npm install
npm run dev
```

Abra o endereço exibido no terminal.

## Verificações

```bash
npm run lint
npm run typecheck
npm test
npm run build
```
